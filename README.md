# かぜ・感染症よぼう（kansen-yobo）

学校・家・電車などの場面を見て、かぜやインフルエンザなど呼吸器の感染症を、うつさない・うつらないために、いちばん大事な行動（手洗い・せきエチケット・マスク・換気・湿度・休むこと）を選ぶ1日5問の学習ゲーム。正解したら「なんのため？」（手から入れない・しぶきを広げない・部屋の空気をととのえる・休んで体を守る）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/kansen-yobo/>
